RIAB

AI and computer vision for tele-rehabilitation (2025–2028). Client: Bilancio CO2 Zero S.r.l. Role: scientific coordinator.

The project develops machine learning and deep learning models to improve remote (tele) rehabilitation, using computer vision to evaluate patients’ movements. I am the scientific coordinator of the project.
